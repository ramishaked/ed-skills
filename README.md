# ed-skills: מפת המיומנויות והערכים

מו"פ מיומנויות, אגף החינוך חולון, תשפ"ז.

כלי צפייה ידידותי למנהלי בתי ספר, שמרכז את המיומנויות והערכים של **דמות הבוגר** (משרד החינוך) לצד כשירויות וערכים ממסגרות משלימות: זרקור כשירויות, Skills Builder, OECD, מסגרת כשירות הבינה המלאכותית של משרד החינוך ורשימה כללית ממרחבי הרשת. פריט שמופיע בכמה מסגרות לא שוכפל: הוא מופיע פעם אחת, והשמות שלו במסגרות האחרות שמורים כ"שמות נוספים".

## מבנה

| נתיב | מה יש בו |
|---|---|
| `index.html` | הכלי עצמו, קובץ אחד עצמאי. זה הקובץ הראשי שמוצג. |
| `src/template.html` | קוד המקור של הכלי, עם מקום שמור לנתונים (`__DATA__`). |
| `data/snapshot.json` | עותק של בסיס הנתונים: פריטים, קשרים ומקורות. |
| `scripts/build.py` | בונה את `index.html` מהתבנית והנתונים. |
| `scripts/snapshot_from_sheet.py` | מושך עותק עדכני מהגיליון המפורסם ושומר ב-`data/snapshot.json`. |
| `docs/status.md` | סטטוס הפרויקט והצעדים הבאים. |
| `docs/decisions.md` | יומן ההחלטות. |

## מקור הנתונים

מקור האמת הוא גיליון Google "מיומנויות וערכים - בסיס נתונים" (לשוניות: פריטים, קשרים, מקורות, רשימות, מיפוי רשימות נוספות). הכלי מציג את העותק שב-`data/snapshot.json`, ובזמן טעינה מנסה למשוך את הגרסה המפורסמת של הגיליון. אם המשיכה מצליחה, בתחתית הדף כתוב "נתונים: מעודכנים מהגיליון".

## עדכון

```
python3 scripts/snapshot_from_sheet.py   # עותק עדכני מהגיליון
python3 scripts/build.py                 # בניית index.html
```

אחרי שינוי ב-`src/template.html` מספיק להריץ את `build.py`.
